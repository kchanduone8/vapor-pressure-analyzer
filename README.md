# Thermodynamic Property & Vapor Pressure Simulation Engine

A computational Python tool that utilizes the Antoine equation to model vapor-liquid equilibria and non-linear vapor pressure curves.

## Key Features
- **Vectorized Array Operations:** Leverages NumPy array broadcasting to compute non-linear temperature-pressure arrays efficiently without standard Python loops.
- **Data Export & Visualization:** Automatically generates dynamic Matplotlib equilibrium plots and outputs structured tabular datasets via Pandas.

## Dependencies
- `numpy`
- `pandas`
- `matplotlib`

## Usage
```bash
python analyzer.py
